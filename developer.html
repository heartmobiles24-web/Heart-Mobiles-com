About the developer

Behind this website

We help businesses establish, strengthen and grow their digital presence through modern web technologies, creative branding and strategic digital solutions.

This website for Heart Mobiles was built as a fast, accessible, mobile-first static site — no heavy frameworks, no unnecessary tracking, and content that the shop can update through simple JSON files.

How this site was built

  • Semantic HTML5 with a mobile-first responsive layout
  • Tailwind CSS compiled to a single production stylesheet
  • Vanilla JavaScript ES modules — no framework overhead
  • JSON-driven content so the shop can edit text without code
  • Structured data, sitemap and metadata for local search
  • Accessible components with keyboard support and reduced-motion handling
